# 2. Informações sobre como vai funcionar ISSUES e PR
***2.1-*** O issue, funcionará apenas como um mecanismo de denuncia, caso algum projeto (Como por exemplo o Godzilla), tenha algum tipo de erro que possa impossibilitar o usuário de resolver-lo.
***2.2-*** O PR, funcionará apenas como um mecanismo de adição de CRACKME da comunidade, é aceito todo e qualquer tipo de crackme desde que seja catalogado de forma correta, Aliás, é necessário que no módulo tenha obrigatoriamente seu nick ou qualquer coisa que seja no comentário no código (não quero que no futuro tenha algum problema com falta de créditos ou alguém enchendo meu saco por causa disso), exemplo:
```cpp
/*

    Project Crack Me
        - Module: YOUR MODULE
        - Created by: YOUR NICK
        - Released in: DATE (optional)
        - Level: ?
        - Description: ? (optional)
*/
```
***2.3-*** Não repita nomes, se o nome que você pensava em usar já existe no modulo que você pretende adicionar, mude-o. Caso por exemplo: Já existe um módulo chamado Godzilla dentro da pasta de nível 1.0, e você quer fazer a continuação do módulo no nível 1.1, 1.2, ou qualquer outro, você precisa pedir autorização do criador do modúlo para continuar-lo.
